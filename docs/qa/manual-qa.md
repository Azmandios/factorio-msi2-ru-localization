# Ручной QA в игре

Автоматические проверки (`make check`, `make smoke`) уже прошли: 490/490 ключей,
латинских остатков нет, названия прототипов в дампе — русские. Ниже — чек-лист для
финальной визуальной проверки в игре.

## Подготовка

1. В Factorio открыть «Моды» и убедиться, что `msi2-ru-localization` включён.
2. Перезапустить игру (мод меняет только локализацию).
3. Язык интерфейса — русский (настройки → язык).

## Чек-лист

### Информатрон (кнопка Informatron, клавиша по умолчанию — `I`)

- [ ] Вкладка «Mining Space Industries II» открывается, приветственный текст на русском.
- [ ] Вкладка «Технологии» — описание утраченных технологий без английских слов.
- [ ] Вкладка «Компаньоны» — описание дрона и синтетика.
- [ ] Вкладка «Доска сообщений».
- [ ] Вкладки «Миссии», «Текущие», «Выполненные», «Проваленные».
- [ ] Карточки миссий: названия, брифинги, условия и награды читаются по-русски,
  без «Unknown key», без торчащих английских фраз.

### Сущности и предметы

- [ ] Дрон-компаньон MSI и Дэвид-синтетик — русские названия в тултипах.
- [ ] Руда «Солаз/Блюдаз/Уваз» на карте и в тултипах.
- [ ] Обломки корабля (`crash-site-*`) — «Повреждённая лаборатория» и т. п.
- [ ] Заражённые гнезда протомолекулы, боссы (кусака/плевака/червь) — русские.
- [ ] Предметы: контейнер MSI, снайперская винтовка, антидотная бомба, рельсотрон.

### Технологии и настройки

- [ ] Технологии MSI (сканирование протомолекулы, улучшение дрона и т. д.) —
  русские названия и описания.
- [ ] Экран «Настройки» → «Настройки модов»: пункты MSI и Rocket-Silo-Construction
  на русском, подписи диапазонов (`0.2 - 10`) не тронуты.

### Панели дрона/синтетика

- [ ] Кнопки «Следовать за мной», «Домой», «Охранять на месте», «Производить науку»,
  «Добыча» — русские подписи и тултипы.
- [ ] Статусы «Следует / Охраняет / Производит / Усиливает / Добывает».

## Что делать, если найден дефект

1. Найти ключ в `tools/source/<мод>/en.cfg` и его перевод в `locale/ru/*.cfg`.
2. Поправить перевод.
3. `make check` — должно быть 0 ошибок.
4. `make install` и перезапуск игры.

Найденные дефекты и их исправления фиксируются в этом файле ниже.
