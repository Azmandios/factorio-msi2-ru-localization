# Стайлгайд перевода

## Тон

Оригинал MSI2 — неформальный, с армейским юмором от «контроля миссии» (восторги,
паника, шутки про деревья бампером и «недостаточно оплачено»). Перевод сохраняет
эту интонацию, но остаётся читабельным:

- Обращение к игроку — на «вы» («Почините лабораторию…», «Вам нужно…»).
- Реплики контроля миссии — живые, эмоциональные, но без потери смысла.
- Шутки передавать по смыслу, а не дословно; каламбуры адаптировать.
- Не добавлять собственных вставок, которых нет в оригинале.

## Пунктуация и типографика

- Кавычки — «ёлочки»: «…». Внутренние — „лапки“.
- Тире — длинное «—» с пробелами вокруг.
- Многоточие — «…».
- Числа от единиц — неразрывный пробел не требуется (обычный пробел допустим).
- Проценты: `__1__%` без пробела.

## Теги и плейсхолдеры

- `__1__`, `__2__` — сохранять и не менять порядок.
- `__CONTROL__informatron__` — оставлять как есть (подставится клавиша).
- `[img=…]`, `[item=…]`, `[entity=…]`, `[technology=…]`, `[recipe=…]`,
  `[fluid=…]`, `[virtual-signal=…]`, `[color=…]`, `[font=…]` — идентификаторы
  внутри тегов не переводить, сам тег переносить в нужное место предложения.
- `\n` и `\n\n` — сохранять разбивку абзацев.

## Терминология

- Термины Factorio — только по официальной русской локализации: сборочный автомат,
  научный пакет, ракетная шахта, кусака, плевака, червь.
- Сюжетные термины — по `docs/glossary.md`, без синонимов.
- Бренды и имена (`MSI`, `David`, `Nauvis`, `Factorion`, `Compilatron`) — не переводить.
- Коды миссий/технологий — не переводить.

## Числа и единицы

- Числовые значения и диапазоны не менять: `0.2 - 10`, `1-normal, 5-harder`.
- `minutes` → «мин», `meters` → «м».
- `HP` → «здоровье», `XP` → «опыт», `level` → «уровень».

## Формат файлов

- UTF-8 без BOM, переносы строк LF.
- Ключи и значения — без пробелов вокруг `=`.
- Одна строка `ключ=значение`, значения с переносами используют литеральный `\n`.

## Что проверяется автоматически

`make check` проверяет: паритет ключей, сохранность тегов/плейсхолдеров, число `\n`,
отсутствие хвостовых пробелов, остатки английских слов и запрещённые варианты из
глоссария. Перед коммитом перевод обязан проходить `make check` без ошибок.
