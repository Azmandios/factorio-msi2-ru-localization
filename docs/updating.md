# Обновление перевода после апдейта модов

Когда выходит новая версия `Mining-Space-Industries-II` (или переводимых
зависимостей), перевод нужно синхронизировать.

## Шаги

1. Обновить мод в игре или скачать новый zip в каталог модов.

2. Переснять английские исходники:

   ```bash
   make sync-source
   ```

   Обновит `tools/source/<мод>/en.cfg` и `tools/source/manifest.json`
   (версия + sha256 каждого файла).

3. Посмотреть, что изменилось:

   ```bash
   make report --missing
   ```

   Новые ключи без перевода появятся как `MISSING`. Изменённые значения
   обнаружит `make check` (несовпадение тегов/плейсхолдеров) и
   `git diff tools/source`.

4. Перевести новые/изменённые строки в `locale/ru/*.cfg`, сверяясь с
   `docs/glossary.md` и `docs/style.md`.

5. Проверить:

   ```bash
   make check      # 0 ошибок, 100% покрытие
   make smoke      # строки реально применились
   ```

6. Обновить `changelog.txt` и `info.json` (если подняли версию мода-перевода).

7. `make install` и перезапуск игры.

## Как работает определение изменений

`tools/sync-source.py` сохраняет полный текст английских `locale/en/*.cfg` с
sha256. `git diff tools/source/...` показывает построчные изменения английского
текста — это точный список того, что нужно перепроверить, вместо сплошной
вычитки всего мода.
